Simple Editor

A tiny, dependency-free WYSIWYG HTML editor. Plain HTML + CSS + JS — no framework, no build step.

~1 file 0 dependencies MIT sanitized output works with <textarea>

Live output — editor.getHTML() (updates on every change)


        

          Output is sanitized (allowlist) and normalized:
          <b> → <strong>,
          <font color> → <span style>, no scripts, no
          inline event handlers.
        

        

          Tables always span the full width. Drag a column border inside a table
          to resize it — widths are saved as percentages on
          <col> elements, so tables stay responsive on
          mobile.
        

      


      

        
Usage

        
<!-- 1. include the two files -->
<link rel="stylesheet" href="simple-editor.css">
<script src="simple-editor.js"></script>

<!-- 2. a textarea (kept in sync, works with plain form POST) -->
<textarea name="content"></textarea>

<!-- 3. turn it into an editor -->
<script>
  var editor = SimpleEditor.create("textarea[name=content]", {
    placeholder: "Write something...",
    language: "en",          // "tr" also available
    uploadUrl: "/upload.php" // optional: POST multipart "file",
  });                        // expects {"url": "..."} or a plain URL string
</script>

        

          API: getHTML(), setHTML(html),
          onChange(cb), focus(),
          destroy(). Shortcuts: Ctrl+B / I / U, Ctrl+K (link),
          Ctrl+Z / Y.
        

        
CSS for rendered pages (e.g. your PHP template)

        
/* saved content — same responsive table rules as inside the editor */
.content table { width: 100%; table-layout: fixed; border-collapse: collapse; }
.content td, .content th { border: 1px solid #d1d5db; padding: 6px 10px; overflow-wrap: break-word; }
.content th { background: #f9fafb; }

@media (max-width: 640px) {
  .content td, .content th { padding: 4px 6px; }
